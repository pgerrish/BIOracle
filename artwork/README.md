# Graphite & forest green

Eight original BIOracle backgrounds, created with the built-in image-generation tool. Each image is 1536 × 1024 pixels. The full-resolution PNGs are in `originals/`; the website uses optimized WebP copies under `dist/assets/artwork/`.

The collection uses heavy, pressure-varied gray and dark forest-green pencil on pale ivory paper. Sparse surreal forms sit toward the right edge, leaving the left and center open for headlines. These are conceptual artworks, not scientific diagrams or financial data.
